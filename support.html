Пожалуйста, не присылайте пароли, PIN-коды, ключи и конфиденциальные файлы. Для диагностики обычно достаточно описания проблемы и скрина/видео без личной информации.

Коротко о продукте

  • Приватное хранилище для фото и заметок — содержимое предназначено только для владельца устройства.
  • Контроль доступа — вход и доступ к разделам ограничиваются настройками защиты PIN.
  • Шторка приватности — при сворачивании или переключении задач приложение скрывает содержимое, чтобы оно не было видно посторонним.
  • Встроенный браузер — для просмотра веб-страниц внутри приложения.
  • Очистка данных — инструменты для удаления истории/кэша/данных браузера и других локальных следов (в рамках доступных функций).

Быстрые решения

  • Приложение работает нестабильно: перезапустите приложение, обновите iOS, освободите память устройства.
  • Сайт “помнит” меня: используйте очистку данных браузера. Учтите: сайт может хранить сессию на своей стороне.
  • Камера/снимок не работает: проверьте разрешение “Камера” в Настройки iOS → Приложения → TTH BOX.
  • Покупка/активация: убедитесь, что вы вошли в Apple ID и устройство подключено к интернету.

Импорт/экспорт фото и сохранение из браузера

На момент текущей версии приложения импорт/экспорт из системной медиатеки “Фото” отсутствует.

В будущих версиях может появиться возможность сохранять изображения из встроенного браузера с выбором: сохранить в защищённое хранилище TTH BOX или в системное хранилище iOS. При добавлении такой функции приложение запросит соответствующие разрешения, а документация будет обновлена.

Как удалить данные

Мы придерживаемся принципа “пользователь контролирует данные”.
  • Удалить всё сразу: удалите приложение с устройства — iOS удалит данные приложения с устройства.
  • Удалить выборочно: используйте функции очистки внутри приложения (например, история/кэш/данные браузера), если они доступны в настройках.
  • Сброс доступа: если выполнен сброс доступа, приложение удаляет все данные и просит вас ввести ключ активации.

Примечание: сторонние сайты могут хранить данные у себя. Очистка удаляет локальные данные на устройстве, но не управляет данными на стороне сайта.

Что указать в обращении

  • Устройство: модель iPhone и версия iOS.
  • Версия приложения: например 1.0 (1).
  • Шаги воспроизведения: что вы сделали по пунктам и что ожидали.
  • Результат: что получилось фактически (ошибка/поведение) + скрин/видео без личных данных.
